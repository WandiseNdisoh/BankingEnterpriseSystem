# 🏦 Banking Enterprise System

A full-stack enterprise banking management system developed using **ASP.NET MVC 5**, **C#**, **Entity Framework 6**, **SQL Server**, and **ASP.NET Identity**.

The system demonstrates enterprise software development principles by providing a secure platform for managing customers, banking transactions, loan applications, and administrative operations.

---

# 📌 Overview

The Banking Enterprise System was built as a portfolio project to showcase practical software engineering skills using Microsoft's .NET Framework.

The application follows the MVC (Model-View-Controller) architectural pattern while applying object-oriented programming, Entity Framework, authentication, validation, and relational database management.

This project demonstrates my ability to design and develop business applications similar to those used within financial institutions.

---

# ✨ Features

### Customer Management

- Register new customers
- Edit customer information
- View customer records
- Delete customer records

### Loan Management

- Submit loan applications
- Store customer loan information
- Capture salary details
- Maintain loan records

### Transaction Management

- Record customer transactions
- Store transaction amounts
- Manage transaction types
- View transaction history

### Dashboard

- Banking dashboard
- Summary information
- Navigation to banking modules

### Authentication

- User Registration
- User Login
- ASP.NET Identity Authentication
- User Account Management

# 🚀 Getting Started

## Clone the repository

```bash
git clone https://github.com/WandiseNdisoh/BankingEnterpriseSystem.git
```

## Open the solution

Open

```
BankingEnterpriseSystem.sln
```

using Visual Studio.

## Restore packages

Restore the NuGet packages.

## Configure SQL Server

Update the connection string inside

```
Web.config
```

to match your SQL Server instance.

## Run the application

Build the solution and launch using IIS Express.
